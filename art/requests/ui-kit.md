## Prompt
Using the attached gameplay screenshot and clownfish sheet as the style reference (glossy 3D cartoon, soft studio lighting, bright saturated, clean edges),
create a UI sprite sheet for a casual mobile puzzle game, 6 separate items in a grid of 3 columns x 2 rows, each centered in its cell with clear empty space between items:
Row 1: (1) a wide horizontal GOLD ribbon banner with folded tail ends, BLANK (no text), glossy; (2) the same ribbon banner in RED, BLANK (no text); (3) a big glossy GOLD star with a white highlight.
Row 2: (4) an EMPTY star slot: the same star shape but dark navy blue, recessed, unlit; (5) a very HAPPY clownfish (same character as the reference orange clownfish) jumping with a big open smile and sparkles of joy; (6) a SAD clownfish (same character) with teary eyes and a small frown.
No text anywhere. Do NOT use any green color in the items. Plain flat pure green (#00FF00) background everywhere, no shadows on the background, no borders. Landscape image 1536x1024.
